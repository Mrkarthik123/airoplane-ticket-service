# 📱 SkyJet Mobile App

Native Android app (Capacitor wrapper around the SkyJet web UI) + installable PWA.
Backend stays the same Java server — the phone talks to your laptop over Wi-Fi.

## Option A — Install the APK (easiest, Android only)

1. On your laptop, start the server:
   ```bash
   cd airplane-ticket-service
   java -jar SkyJet.jar
   ```
   Find your laptop's LAN IP (macOS: System Settings → Wi-Fi → Details, e.g. `192.168.1.5`).
2. Copy **`SkyJet.apk`** (in `airplane-ticket-service/`) to your phone (WhatsApp/Drive/USB).
3. On the phone, open the APK → allow "Install unknown apps" → Install.
4. Open **SkyJet**, enter the server URL when asked, e.g. `http://192.168.1.5:8080`
   (use `http`, not `https`; phone + laptop must be on the same Wi-Fi).
5. Login with `demo@skyjet.in` / `demo123` and book flights. 🎫
   The ⚙ button in the top bar changes the server URL anytime.

## Option B — Install as PWA (Android + iPhone, no APK)

1. Start the server on your laptop (`java -jar SkyJet.jar`) — same Wi-Fi as the phone.
2. On the phone browser open `http://<laptop-ip>:8080` (e.g. `http://192.168.1.5:8080`).
3. Android (Chrome): ⋮ → **Add to Home screen** → **Install**.
   iPhone (Safari): Share → **Add to Home Screen**.
4. Launch the SkyJet icon — it runs fullscreen like a native app, and the
   shell works offline (bookings always need the server online).

## Rebuild after UI changes

```bash
cd mobile
npm run sync-www          # copy latest web UI (../src/main/resources/static) into www/
npm run build-apk         # sync + Gradle assembleDebug → SkyJet.apk
```

Requirements: Android SDK (`platforms;android-34`, `build-tools;34.0.0`),
Java 21 (`brew install openjdk@21`), Gradle 8.11. See `build-apk.sh`.

## Layout

```
mobile/
  package.json / capacitor.config.js   ← Capacitor wrapper (appId in.skyjet.app)
  www/                 ← bundled web UI (generated by sync-www, git-ignored)
  android/             ← native Android project (generated by `cap add android`)
  tools/IconGen.java   ← generates the app icons
  build-apk.sh         ← one-command APK build
```
